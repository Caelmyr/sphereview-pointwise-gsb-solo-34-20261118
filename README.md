# SphereView 全景照片工作台

在一张经纬全景图中浏览方向、取出透视照片、调整整站水平姿态，并为下次审阅保存取景。点击“载入合成演示”体验具有不同方位标牌的虚构观景地点。演示图由代码绘制。

## 启动

执行 `docker compose up -d --build`，访问 http://127.0.0.1:18937/ 。Compose 使用独立数据卷。Dockerfile 使用已有的本地依赖镜像 `solo36-tracedesk:1.0` 缩短构建。没有镜像时可在独立的 Python 3.11 或 3.12 环境执行 `pip install -r requirements.txt` 和 `python -B app.py`。可用 `SPHEREVIEW_DATA_DIR` 设置数据目录，默认 `data/`。宿主启动默认绑定回环。

## 工作方式

1. 导入宽高比 2:1 的经纬 PNG/JPEG，或载入合成演示。点击下方方向条切换当前取景中心。
2. 调节透视画面的方向、旋转、水平视角和画幅。存为可恢复的取景书签，或直接下载当前照片。
3. 在方向图上切到“添加入口”，点选入口位置并填写 A1、B2 这类 1–4 位字母数字编号，可勾选重点编号。每个项目最多保存六个入口，支持删除。切回“导航取景”后点击方向图仍按原方式转动取景。
4. 透视取景只标注实际落在画内的入口：编号自动挪位避免互相重叠、盖住其它入口或让引线穿过别的标牌，实在放不下时优先保住重点编号，并在画面下方列出画外与未显示的编号。页面所见即下载所得，取景 PNG、书签预览和工程 ZIP 内的照片由同一套后端布局烘焙，方向图上的标牌位置也取自同一布局。
5. 调整全景的站点姿态或曝光，切换到“校准全图”检查并下载。站点姿态作用于所有派生视图，书签保存相对这个工作坐标的取景参数，入口标注同样按工作坐标投影。
6. 可打开原图探针和左右接缝读数，或切到立方体六面和小行星查看不同输出。工程 ZIP 包含原图、参数、书签、入口标注和取景 PNG，可在新项目中恢复。
7. “图像准备”是独立二维工作区，提供常规图像校色、配准、对照及归档。可下载准备结果再导入全景工作台。

输入宽度 128–2048 像素、单图最大 16 MB，取景最长边 768，立方体每面 384，小行星 640。规范化原图以 PNG 留存，按 EXIF 方向归正。采样使用经度周期双线性插值、纬度夹紧及预乘透明度插值。曝光是显示色值上的近似调整。接缝读数比较源图第一和最后一列的有效像素，能定位突变方向供人工判断。该工作台以已有全景为输入。
